# LumenDock

Turn a spare Android phone into a USB desk display for Claude Code/Codex subscription limits and selected laptop notifications, while its Wi-Fi controls an ESP32 light and shows room temperature/humidity.

**Build in progress.** Desktop, Android and dashboard components are being independently reviewed; physical Redmi/ESP32 acceptance is deferred.

Start with [HANDOFF.md](HANDOFF.md), [machine-readable status](docs/STATUS.json), [coordination](docs/COORDINATION.md), and the [PRD](docs/PRD.md). Implementation runs in the managed worktree identified in the handoff. Final setup, packaged APK and checksums will be added after integration and the required final review.
