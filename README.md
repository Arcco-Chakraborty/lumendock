# LumenDock

Turn a spare Android phone (target: Redmi 9A) into a USB desk display for Claude Code/Codex subscription limits and selected laptop notifications, while its Wi-Fi controls an ESP32 light and shows room temperature/humidity.

**Status:** software built and checked (unit, browser e2e, Android JVM tests, packaging). Not yet run on the real phone or controller, and the required gpt-6-astra final review is still pending; see [docs/DEVICE_ACCEPTANCE.md](docs/DEVICE_ACCEPTANCE.md).
