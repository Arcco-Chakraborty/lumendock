# Desk instrument design

Monitor keeps the local clock and room together at left. Two equal usage readouts at right make provider limits comparable at a glance; a single alert rail sits below. Deck keeps the existing app, media/audio and light banks. Labels carry application identity instead of invented brand marks. The retracting dock reads as one physical control strip.

Palette: graphite canvas #202321; recessed field #292e2b; raised keys #353d38; light text #edf0e8; secondary text #b5beb6; mineral teal #a9c9c0 for selection/focus; brass #d6bd83 for caution. Flat fills, no atmospheric gradients, glow or blur.

Type: Arial with system sans fallback, consistent tabular numerals. The clock has one large, light readout with a small but legible AM/PM. Quotas use the same numeric hierarchy, sentence-case labels and plain reset text. Normal copy is at least 14px. There is no decorative heading or metadata filler.

Layout:

    clock + date   | Claude usage | Codex usage
    room readings | recent alert + details
                  [retracting navigation strip]

    Apps          [named application keys]
    Audio         [transport] [volume]
    Lighting      [RGB presets] [power] [controls]
                  [retracting navigation strip]

Plan critique: an all-dark identical card grid would still resemble the previous design. The clock therefore sits directly on the canvas; room has a simple separating rule; usage shares one recessed field with a central divider. Only actionable Deck keys are individually raised. Colour shows state and light selection, not provider branding.
